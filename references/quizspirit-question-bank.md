# QuizSpirit 範本、配樂與換題庫

本模式適用「沿用這次題靈數學對戰畫面，換成國文／其他科題庫」「做同款答題對戰網站」「保留配樂、換一份題庫」。一般 RPG 仍依主技能與既有專案；不要把 QuizSpirit 的角色、數值、顏色或儲存方式套成全域規則。

## 先辨識使用者要換什麼

- **只換題庫**：既有畫面、音樂、戰鬥、角色與存檔規則保留；從提供的副本處理，核對題數與答案。已確認換題庫時，直接轉換、檢查與匯入，不再要求一次風格確認。
- **建立同款新遊戲**：使用隨附獨立範本，不依賴過往聊天路徑；重要視覺或規則變更依使用者協作要求先確認。
- **正式帳號／考試**：範本是前端自學遊戲，HTML 含答案；若要求防偷看或跨裝置帳號，需改服務端判題／權限／保存方案，不可把內嵌答案宣稱為安全考試。

## 複製可運作範本

```text
node <技能目錄>/scripts/create-quizspirit-project.mjs <新的空白專案資料夾>
```

程式只複製 `assets/quizspirit-template/`，遇非空資料夾停止。範本含 React 畫面、CSS、分層森林 SVG、原創 Web Audio 配樂、音效、64 張角色立繪、題庫匯入器與獨立抽題核心。沒有 node_modules、預設帳號、金鑰、雲端服務或公開部署。

依當次執行環境找到 Node.js 與可用套件管理器。安裝 package.json 的套件，執行 build，然後：

```text
node scripts/export-standalone.mjs
```

匯出專案根目錄 `QuizSpirit_題庫切換版.html`。開啟檔案即可玩，原創角色圖全部內嵌，不連外部圖庫；只有 Google 字型需要網路，離線時改用系統字型。配樂由瀏覽器合成，可離線運作。圖片改名或改路徑後需同步調整匯出器，不繼續交付缺圖檔。

若建置遇到目錄讀取限制，依當次工具權限處理；不可將繞過限制寫成流程。不要複製 node_modules 或依賴開發用伺服器作為可攜交付。

## 題庫契約

沿用 [curriculum.md](curriculum.md) 的四選一格式，加上題庫外層資訊。範例位於 [../assets/quizspirit-template/public/sample-bank.json](../assets/quizspirit-template/public/sample-bank.json)，其題目為 `review`，展示欄位，不自動當正式教材。

```json
{
  "schemaVersion": 1,
  "bankId": "chinese-grade8-unit1-v1",
  "title": "國二國文第一課",
  "subject": "國文",
  "timeLimitSeconds": 30,
  "questions": [{
    "id": "來源題目穩定ID",
    "unit": "單元名稱",
    "stem": "保留來源題幹全文",
    "options": { "A": "選項一", "B": "選項二", "C": "選項三", "D": "選項四" },
    "answer": "B",
    "explanation": "原始解析或教師確認的解析",
    "sourceRef": "原檔名稱、頁碼與題號",
    "status": "review"
  }]
}
```

- `bankId` 為 1–80 位小寫英文、數字、底線或連字號，首字為英文或數字；保留 `math-auto` 給原本的自動算術。題庫更新使用版本 ID，不自動覆寫已匯入內容。
- `active` 才能出題；`review` 永遠排除。沒有答案、缺圖、OCR 不確定、AI 補寫的答案或解析預設留待複核，標示「AI 草稿，待教師確認」，不可為了湊題數偷偷改為 active。
- active 題必須有 `id/unit/stem/options/answer/explanation/sourceRef`。A–D 選項不能空白或重複。答案以字母對應，不以索引、顏色或選項文字猜測。
- `timeLimitSeconds` 可省略，匯入題庫預設 30 秒；若提供需為 5–600 的整數。依閱讀量與使用者需求調整，不把原版數學的 10–15 秒硬套到國文閱讀題。
- `difficulty` 可省略，若提供為 easy/medium/hard/champion。招式優先抽同難度的 active 題，沒有時回退到該庫所有 active 題；四選一以外的題型需另擴充轉接器，不硬轉。
- Word/PDF/Excel 應先用當次相應技能抽取、核對答案，再輸出 JSON。只有轉檔要求時不額外命題；不把長篇閱讀材料截斷或臆造圖表。

## 匯入與抽題行為

首頁「匯入 JSON 題庫」支援多檔，逐檔驗證；壞檔、重複 bankId 與超過 5 MB 的檔案顯示原因，不刪改既有題庫。全 review 題庫可保留供核對，但下拉選單中不可出戰。匯入後由「目前題庫」下拉選單切換，也可回到「自動數學練習」。

題庫資料保存在同一瀏覽器的 localStorage，受檔案路徑、瀏覽器、隱私模式與資料清除影響；儲存失敗顯示本次有效。這不是跨裝置同步。基礎範本的玩家收服紀錄重新整理會重設；如使用者要錯題本、進度保存、掌握度或圖鑑稱號，依 [學習與收藏擴充](quizspirit-learning-collection.md) 加入隨附可選套件，再依實作說明保存範圍。

每份題庫／難度有獨立洗牌佇列，抽完再洗牌；同題不同庫以 `bankId:questionId` 區隔。切庫清除抽題佇列與上一題解析，不混入他庫內容。答對、答錯與逾時後皆顯示正確答案、解析與來源，下一題開始前保留回饋。解析不能使用 HTML 注入或 eval 題幹；React 文字渲染不執行匯入內容。

## 畫面與聲音

沿用已確認的深藍／電光黃冒險風、完整比例角色卡、森林場景與手機單欄長選項。需要重新設計時才擴充，不因換題庫重畫角色。

配樂由 `src/music.js` 合成四個場景：adventure、battle、victory、rest。第一次點擊或按鍵後解鎖音訊；配樂開關／音量與音效開關獨立。場景切換停止舊排程與聲部，切到背景暫停，返回恢復；若瀏覽器暫停音訊，需操作後 resume。不要用未授權的商業遊戲曲目代替原創合成旋律。

戰鬥畫面狀態獨立於題庫；下一場需清除角色退場動畫、傷害提示。落敗重試恢復角色 HP。換題庫不順手改傷害、收服率或新增帳號服務。

## 驗證及交付

1. 題庫先跑共通 audit，再用範本 `validateBank()` 核對外層、來源與可用題數，對照原教材抽查。兩者只是結構檢查，不能取代教師審題。
2. 瀏覽器實測匯入兩份不同庫、切換、active/review、無效答案、重複 ID、無效 JSON、無可用題、重載後題庫保存；失敗不得毀掉原有庫。
3. 實測答對、答錯、逾時的戰鬥與答案解析；長中文題幹／選項可完整閱讀。桌面與手機看實際 `innerWidth`，避開瀏覽器縮放造成假 390px；確認不橫向溢出。
4. 配樂需要驗證 AudioContext 的實際非零輸出、開關、0% 音量、場景切換、停止舊聲部；僅看「正在播放」文字不足以證明有聲音。
5. 重開最終獨立 HTML，核對角色立繪、離線靜態備援與 JSON 匯入，不以開發預覽成功代替成品驗證。
6. 交付 HTML、獨立 JSON 題庫、可修改專案和簡短用法；本機預覽不宣稱已上線。原檔不變，公開部署另依使用者授權處理。

## 原創題庫經教師確認後啟用

使用者要求自編練習題時，先核對學科分類用語及解析，交付可逐題檢視的草稿。教師明確表示「題目 OK」後，將同一份已確認題目由 review 改為 active，重新跑 audit 與 validateBank，設定為預設題庫，重新 build 和匯出 HTML。確認檔名、題庫標題與畫面都已更新，避免已批准的國文網站仍預設數學題。後續教師指定的陷阱題保留原句，解釋詞語的實際功能，不以單字命中猜句型；如整句分類有爭議，可改考分析理由。

國中國文四大句型案例：敘事句、表態句、判斷句、有無句。「他總是很聰明」以「很聰明」描述性質，不因出現「是」判為判斷句；「我只有努力讀書才行」的「只有……才……」表必要條件，不因出現「有」判為有無句。這是本次教學案例，不當作所有教材的分類依據。
