# 原創角色、透明素材、動畫與聲音

## 圖像設計及正式素材

先確認題材、受眾、原創角色、構圖、風格、配色、文字限制與透明需求。適合比較的方向可先用清楚標示的輪廓草圖展示；不要把 SVG 草圖冒充完成的正式插畫。當使用者要點陣角色，有圖片生成工具就用；沒有時用技能的 `tools/make_art.py` 產生原創角色（見下方），或請使用者提供有權利的圖片。不用 CSS 墨球替代有具體形象的妖獸。

內建生圖優先；透明需求使用真正透明背景選項。若工具失敗，先說明再取得 CLI／外部 API 路徑的授權，不暗中改模型、啟用付費服務或暴露 key。圖像、文件及其他專門工具依當次技能規範處理。

生成後查看角色、名稱對應、完整四肢／角／尾與留白，檢查 actual alpha、尺寸與檔案存在；黑色檢視背景不代表已去背。保存原圖，將正式資產複製進專案，不能只引用生成工具的暫存路徑。服飾多變體以角色 × 主題 × 成長階段列清單，逐一核對，別把「生成成功」當「全部素材已交付」。

## 不使用既有作品的角色

不使用寶可夢、數碼寶貝、迪士尼、任天堂等既有作品的角色、名稱、圖片或招牌設計（例如雙色分隔的捕捉球、黃色電氣鼠配紅腮紅），也不從 PokeAPI 等第三方圖庫抓圖。使用者要求「同款寶可夢」時，說明會改用原創題靈，玩法與畫面風格可以保留。

## QuizSpirit 原創角色產生器

- 名冊：`tools/roster.py` 的 `ROSTER_TYPES`（id → 英文名、中文名、屬性）。id 是程式內部編號，起始夥伴固定為 1／4／7／25 系列。
- 產生：`python3 tools/make_art.py <輸出資料夾…>`，需要 `rsvg-convert`。依屬性決定配色與頭頂特徵，依 id 決定耳朵、花紋與色相，依進化階段放大並加裝飾；輸出 256×256 透明 PNG。
- 新增角色：在名冊加一行，同步更新範本的 `shared/catalog.js`（或 `src/App.jsx` 的名單）與 `src/growth.js`（若是起始夥伴），重新產生圖片並檢查透明背景。
- 換成手繪或生成的正式插畫時，維持同樣檔名（`public/assets/<id>.png`）即可。

## 低成本動畫與進階動畫分清楚

整張 PNG 可以用 wrapper 做浮動、短衝、震動、閃光、跳躍、淡出與墨霧；這不是尾巴／四肢各自活動。真正逐格、影片或骨架動畫需另行確認工時與素材，不擅自升級需求。

動畫狀態讀既有成功結果，不呼叫新的遊戲 API：

- 主角：idle、attack、hurt、victory；勝利優先於最後一題攻擊，失敗是否倒地由規格決定。
- 敵人：idle、hit、defeated；以正式勝利結果判定，不另外憑剩餘 HP 改勝敗。
- 以戰鬥／題目 ID 區分每題，以動作狀態控制一次性重播；音量操作或重新 render 不重新播放。

外框保留尺寸，圖片與光暈一起動、血條不移動。檢查小螢幕與動畫最大位移：不蓋題目、選項、技能或解析。減少動態偏好停用或簡化位移與閃光；背景頁面可暫停，返回不重播已結束動作。圖片載入失敗時保留可辨識備援與替代文字，不阻擋答題。

## 原創合成配樂

可選 Web Audio 合成的五聲音階地圖配樂及較快戰鬥配樂，或使用有明確授權的音樂來源。合成古琴風不可描述為真實古琴演奏。沒有來源授權就不取用商業手遊配樂。

AudioContext 在使用者手勢後建立／恢復；初次與重新整理預設靜音。音樂和音效獨立開關、音量，記憶音量但不自動恢復播放。這是瀏覽器本機設定，不是帳號雲端存檔。

單一音訊引擎管理場景與排程，限制 lookahead、聲部及事件去重；場景切換淡出舊聲，關閉／隱藏停排程，卸載清理 context。成功結果播放對應音效，勝敗／升級優先避免同時堆疊；模糊寫入重試不得造成重複播放。音訊失敗獨立提示，不顯示為登入或答題失敗。

## 驗證的說法要精確

測試真實 AudioContext、停止及恢復、場景切換、連續循環、重複事件與清理。可用 OfflineAudioContext 驗證非靜音、峰值與無削波，產出試聽檔；不能因此宣稱親耳確認主觀聽感。

模擬 visibilitychange 只能證明相應事件處理，不宣稱已在真實手機作業系統切換 App 驗證。動畫不只查 class 名稱，還要實測 computed style／時間點位移與完成後狀態。

若使用者已取消把配件疊在原角色上的做法，不把它重新包裝成換裝完成；先做整體重繪預覽再確認，見 [quizspirit-companion.md](quizspirit-companion.md)。

老師投影可用既有角色整圖位移、發光及獨立攻擊特效；不是角色逐格重繪。雙畫面與樣式衝突的檢查見 [quizspirit-projector-battlefield.md](quizspirit-projector-battlefield.md)。


## AI 產圖的檢查

先產 1–4 張讓使用者選風格再量產。逐張看肢體數、誤畫與背景；量產後掃描所有圖片邊緣 alpha，找出半透明底紋並清除。像素風神獸、篇章背景與道具圖的案例見 [quizspirit-shanhai-case.md](quizspirit-shanhai-case.md)。
