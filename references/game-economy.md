# 關卡、成長、錯題與造型經濟

## 關卡與勝敗

確認單元順序、鎖定條件、每場抽題上限、初始 HP、傷害、連擊、提前結束及通關判定。明確分開「戰鬥得分」「XP」「抽卡貨幣」，不因畫面像打怪就自行推定打空 HP 是唯一勝利條件。

若勝利依正確率，指定分母是出題總數或已作答數，包含提前結束案例。題數較少的錯題場仍應有明確規則。單元共通題與綜合關卡的首次獎勵依題目 ID 去重。

技能可設定機率與保底，但需要描述保底是每場重新計數還是帳號累積。重答保護清楚定義：第一次錯誤是否記歷史、扣血、增加錯題、顯示答案，以及再次作答如何結算。

## XP 與進化要先算可達性

確認首次答對 XP、重複答對 XP、答錯 XP、通關加成、等級公式與進化門檻。首次依歷史而非本場判斷，跨單元抽到同一 ID 不應再算新題。

設有效唯一題數 N、首次 XP F、重複 XP R、目標 XP T：

- 全題首次答對上限為 N × F。
- 若差額大於 0 且 R > 0，至少需 ceil((T - N × F) / R) 次額外答對。
- 若不足且 R = 0，目標不可達；告知使用者，不偷偷修改數值。
- 「200 題的 XP」是量的比喻，不等同答題總次數；說明重複與答錯影響。

等級公式與 UI、資料庫及手冊用同一份規則。檢查 Lv. 1 的初始區間、每個門檻及最大等級；別假設從新帳號第一次升級起就是固定 24 XP。滿等是否繼續累積 XP 應另外定義。若只獎勵外觀，不擅自增加 HP、傷害或技能機率。

## 再入輪迴

用逐題紀錄管理錯誤次數、連續答對、是否掌握。明確定義「連續」是同題的相鄰紀錄或整場連擊、其他關卡答對是否算、再次答錯是否回到錯題池。每場從待複習池抽不重複題，少於上限時縮小題數，不假造新題。

首次掌握不同題的獎勵，用獨立領取紀錄保存。已掌握題再次答錯、再掌握不應反覆領「首次」券。錯題全部清空時，顯示空態並停用無題目按鈕。

## 服飾抽卡，不把運氣變成戰力

若使用者要純外觀收藏，設定稀有度、公開機率、保底、重複補償、指定兌換與裝備範圍。抽卡機率加總 100%；保底機率與一般機率分開。說明保底是否保證新造型。

貨幣與獎勵要有明確用途及可核對的來源：例如首次答對不同題目、首次掌握不同錯題、每單元首次通關。依永久來源標記防重複發券；券與 XP 不混算。抽卡與兌換原子扣款，重送不重扣。裝備已有造型不扣兌換貨幣。

確認每日登入、付費、排行榜、交換或增強戰力是否真的在需求中；沒有就不加。不鼓勵學生故意答錯刷錯題獎勵。

將同一靈獸的主題服飾套用到不同成長階段。預覽高階圖片不改等級，取得衣服不直接取得進化能力；目前階段由玩家等級決定。

固定夥伴／手動進化／收服選角與道具案例，見 [quizspirit-companion.md](quizspirit-companion.md)。數值限案例，不自動套用到其他遊戲。
